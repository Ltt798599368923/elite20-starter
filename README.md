\## 这是什么



这是一个帮你自动处理重复工作的工具包。你将会得到：



\- 一个能自动给笔记加日期的脚本

\- 一个能整理下载文件夹的脚本  

\- 一个GitHub作品集

\- 一套可重复使用的任务拆解方法
